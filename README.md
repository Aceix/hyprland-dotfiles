# hyprland-dotfiles

My Hyprland desktop on Arch Linux: Lua-based Hyprland config, Noctalia shell, Neovim (NvChad), kitty and friends.

> Work in progress. The `arch-install.sh` / `arch-post-install.sh` scripts **do not work yet**, so don't run them.

## What's here

| Dir | What |
|---|---|
| `hypr/` | Hyprland (`hyprland.lua` + `modules/`), hypridle, hyprlock, hyprpaper, hyprsunset, scripts, sounds |
| `nvim/` | Neovim config built on NvChad |
| `kitty/` | Terminal config and theme |
| `waybar/`, `waybar-alt-1/`, `waybar-alt-2/` | Waybar setups (main + two alternates) |
| `swaync/`, `wlogout/`, `wofi/` | Notifications, logout menu, launcher |
| `bash/` | `.bashrc` |

## Install

Back up your existing configs, then symlink what you want:

```sh
git clone https://github.com/Aceix/hyprland-dotfiles.git ~/hyprland-dotfiles
cd ~/hyprland-dotfiles
for d in hypr nvim kitty waybar swaync wlogout wofi; do
  ln -sfn "$PWD/$d" ~/.config/$d
done
ln -sf "$PWD/bash/.bashrc" ~/.bashrc
```

## Personal settings

Nothing machine-specific is committed. Put your own bits in these untracked files:

- **`~/.bashrc.local`**: aliases, server addresses, API keys. Sourced at the end of `.bashrc`. See `bash/.bashrc.local.example`.
- **`~/.config/hypr/hyprmoncfg-monitors.lua`**: your monitor layout, generated by hyprmoncfg. Loaded if it exists; otherwise `hypr/modules/monitors.lua` uses every monitor at its preferred mode.
- **Neovim Live Share name**: asked the first time you host or join a session. Change it with `:LiveShareName`.
